# Stackly - Developer Dashboard & Learning Platform

Stackly is a modern, interactive dashboard and learning platform for developers, built with Next.js 16, TypeScript, TailwindCSS v4, and Framer Motion. 

## 🚀 Current Features
- Interactive Dashboard Interface
- CSS Themes Gallery
- Button & Icons Gallery
- Code Playground
- Placeholder Modules for HTML, CSS, JS, and Tailwind courses

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** React Icons (Feather)
- **Language:** TypeScript

## 🔮 Future Roadmap (Features to Add)

We are actively evolving Stackly from a UI gallery into a full-fledged Developer Learning Platform. The following features are planned for future development:

### 1. The Curriculum Expansions
- **React.js Course:** Hooks, components, state management
- **TypeScript Essentials:** Interfaces, generics, strict typing
- **Next.js Deep Dive:** Server Components, routing, data fetching
- **Node.js & Express:** Backend APIs
- **Database Fundamentals:** SQL, PostgreSQL, Prisma

### 2. Progress Tracking & Gamification
- **Local Progress Saving:** Track completed lessons using `localStorage` without needing user accounts initially.
- **Visual Progress Bars:** Dashboard indicators showing completion percentage.
- **Achievements & Badges:** Unlockable badges for streaks and module completions.
- **Interactive Quizzes:** End-of-module quizzes to test knowledge.

### 3. Developer Experience (DX) Features
- **Global Command Menu (Cmd + K):** Quick search palette to navigate the entire platform instantly.
- **Bookmarking:** Save favorite code snippets, lessons, or themes for easy access later.
- **Dark / Light Mode Toggle:** Seamless theme switching for the dashboard.
- **Live Code Execution:** Run HTML/CSS/JS directly within lessons via enhanced code playgrounds.
